# 安装包说明

从 [Releases](https://github.com/NapNeko/NapCatQQ/releases/latest) 下载所需安装包：

| 文件 | 用途 |
| --- | --- |
| `NapCat.Shell.zip` | Shell 通用包，需另外安装 QQ |
| `NapCat.Shell.Windows.OneKey.zip` | Windows 一键安装器，自动部署 QQ 和 NapCat |
| `NapCat.Shell.Windows.Node.zip` | Windows Node 运行包 |
| `NapCat.Framework.zip` | LiteLoaderQQNT 插件包 |

安装步骤见 [Shell](./Shell.md)或 [Framework](./Framework.md)。
