# Framework

适用于已有 LiteLoaderQQNT 环境的桌面 QQ。服务器部署使用 [Shell](./Shell.md)。

1. 按 [LiteLoaderQQNT 文档](https://liteloaderqqnt.github.io/) 安装框架，并确认其支持当前 QQ 版本。
2. 下载 [NapCat.Framework.zip](https://github.com/NapNeko/NapCatQQ/releases/latest)。
3. 在 LiteLoaderQQNT 设置中导入压缩包，重启 QQ。

![导入插件](/assets/boot/BootWay01/ll01.png)

启动后在 WebUI 中[配置 OneBot 连接](../../config/basic.md)。
